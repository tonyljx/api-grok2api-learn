# Grok2API 101：1-2 天快速上手导读

> 目标：让你在 1~2 天内建立“代码地图 + 核心链路 + 故障定位”的最小闭环。

## 你先记住这 4 件事

1. **这是一个 FastAPI 网关**：把 OpenAI 风格请求转换为 Grok Web Reverse 请求。  
2. **Token 是一等公民**：所有稳定性、吞吐、可用性都围绕 Token 池调度与状态管理。  
3. **三层结构很清晰**：`api`（协议适配）→ `services/grok`（业务编排）→ `services/reverse`（上游通信）。  
4. **高频功能集中在少数文件**：先把入口、Chat/Image/Video、TokenManager 看懂，就能覆盖大部分需求。

---

## 推荐阅读顺序（建议照这个来）

### 第 0 步（30 分钟）：建立目录心智
- 先看：`main.py`、`config.defaults.toml`
- 目标：知道服务怎么启动、默认开关有哪些、路由被挂载到哪里。

### 第 1 步（2~3 小时）：打通主请求链路
- 先看：`app/api/v1/chat.py`
- 再看：`app/services/grok/services/chat.py`
- 最后看：`app/services/reverse/app_chat.py`
- 目标：从 `/v1/chat/completions` 到上游事件流返回，能画出完整时序。

### 第 2 步（2 小时）：掌握 Token 调度
- 先看：`app/services/token/manager.py`
- 再看：`app/services/token/pool.py`、`app/services/token/models.py`
- 最后看：`app/services/token/scheduler.py`
- 目标：知道“如何选 token / 何时降级 / 怎么刷新配额 / 多 worker 如何一致化”。

### 第 3 步（2~3 小时）：看多模态差异点
- 图片：`app/api/v1/image.py` + `app/services/grok/services/image.py`
- 图片编辑：`app/services/grok/services/image_edit.py`
- 视频：`app/services/grok/services/video.py`
- 目标：知道不同模型在参数验证、上游协议、输出格式上的差异。

### 第 4 步（1 小时）：看运维与管理接口
- 配置与存储：`app/core/config.py`、`app/core/storage.py`
- 管理接口：`app/api/v1/admin_api/*.py`
- 页面路由：`app/api/pages/*.py`
- 目标：能快速改配置、查 token 状态、清缓存、定位线上问题。
